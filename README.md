# New Year Web Animation

This small project showcases the **New Year** animation build using the HTML Canvas.

This project uses **React 19** and **TypeScript**.

## Clone the repo

To clone the repo and run it on your local machine, copy the command below:

```bash
  git clone https://github.com/leesdonson/new-year.git
```

## Install Dependencies

After cloning the repo, you need to install all the dependencies for the project.

```bash
npm install
```

## Run the app

After the installation has completed, you are ready to see the magic in your browser.

```bash
npm run dev
```

## Browser preview

Copy the URL and paste it on your Browser's new tab and watch the magic happens.

```bash
http://localhost:5173/
```
